🌍 Open World Filter

Свежие списки блокировок РКН и ресурсов, недоступных из РФ, с полной историей происхождения. Репозиторий.

Как подключить / How to install

🇷🇺 Инструкции

  1. Скачай свой VPN-клиент (Hiddify, Clash Meta, v2rayN или Throne) и добавь свои серверы.
  2. Импортируй конфиг или rule-sets по ссылкам ниже (подписка содержит только правила).
  3. Готово: заблокированные домены и подсети пойдут через прокси, остальное — напрямую.

🇬🇧 Instructions

  1. Install your VPN client (Hiddify, Clash Meta, v2rayN or Throne) and add your servers.
  2. Import a config or rule-sets from the links below (rules only, no proxy nodes).
  3. Done: blocked domains/IPs go through your proxy; everything else stays direct.
