# Templates (M2)

Сюда появятся шаблоны подписок/конфигов, рендерящиеся из собранных entries.jsonl:

- clash-meta-config.json   — Clash Meta (JSON = валидный YAML) с rule-providers на наши .srs
- sing-box config          — со ссылками на .srs/.db (Hiddify и другие sing-box клиенты)
- v2rayn routing snippet   — импортируемый routing для geoip/geosite .dat
- профили Throne           — через существующий routeforge

Подписки содержат ТОЛЬКО правила; прокси-ноды пользователь вставляет свои.
